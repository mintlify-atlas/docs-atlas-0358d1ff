Cue is a self-hostable personal assistant built for people who have a lot to remember. Type `dentist friday 6pm`, press Enter, and Cue resolves the date, checks for clashes, schedules a reminder, and keeps at you until it is done. It understands English, Hinglish, and Hindi — no model required for the vast majority of inputs.

## Getting started in four steps

<Steps>
  <Step title="Install dependencies">
    Clone the repo and install with `npm install`. Node ≥ 22 and a local PostgreSQL instance are the only prerequisites.
  </Step>
  <Step title="Create the database">
    Run `npm run db:setup` to create the `cue` role and database, then `npm run db:migrate` to apply all migrations.
  </Step>
  <Step title="Seed and run">
    Run `npm run seed` to load demo data, then `npm run dev` to start the API on port 3002 and the web app on port 5173.
  </Step>
  <Step title="Open and install">
    Navigate to `http://localhost:5173`, sign in as `demo@cue.local` / `demo1234`, and optionally install the PWA to your home screen to enable push reminders.
  </Step>
</Steps>

<Note>
  No third-party API key is required to run Cue. Place lookup defaults to OpenStreetMap (free), and the AI capture fallback is off by default. Only `DATABASE_URL` and `JWT_SECRET` are required to start.
</Note>
